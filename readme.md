4. 문제는 그 책을 어디API를 가져와야할지를 몰라서. 이거는 너가 찾아봐줬으면 좋겠어

11. ⭐ 시선 기반 "읽기 자세/거리" 관리
이건 외부 앱에서도 가능하고 책에 특화하기도 쉬워.

사용자가 책을 읽는 동안 시선을 계속 추적하면서

얼굴과 화면의 거리

화면을 보는 각도

고개가 기울어진 정도

시선이 화면에서 벗어난 시간

등을 측정하는 거야.

예를 들어:

📖 독서 자세가 좋지 않습니다.
화면과 얼굴이 너무 가깝습니다.

또는

👀 잠시 쉬어가는 건 어떨까요?
38분 동안 계속 독서 중입니다.

이건 네이버시리즈든 리디든 Kindle이든 화면 내용을 전혀 몰라도 작동해.

그리고 내가 보기엔 방향을 이렇게 잡는 게 제일 좋아
단순히

"눈으로 책을 조작한다."

보다는

"눈으로 읽는 행위를 측정해서 독서 경험을 개선한다."
로 잡아.

그러면 네이버시리즈를 직접 건드릴 수 없는 게 오히려 문제가 아니게 돼.

네 앱은 책의 내용을 볼 필요가 없어.
사용자가 **“책을 읽고 있는 상태”**만 알면 되는 거니까.

그리고 여기서 한 단계 더 나가면 꽤 재미있는 연구 질문도 만들 수 있어:

“스마트폰의 시선 데이터를 이용해 사용자의 독서 집중도와 피로도를 추정할 수 있는가?”

이건 캡스톤/졸업작품으로도 훨씬 그럴듯한 주제가 돼.

특히 나는 ① 독서 집중도 + ② 피로/졸음 감지 + ③ 페이지별 시선 heatmap 이 세 개를 묶는 방향을 제일 추천해.
